## Found and fixed

- **Highlights hid their text.** The first captures showed foliate's overlay painting the tint over the words. The tint now goes behind the text (see Highlights above).
- **The selection used an accent tint.** S4 says selection uses the system colour, and Screens 06 and 14 draw it. The book's `::selection` override is removed.

- **A replaced book was still read from the old file.** The core kept the open book's zip archive by book id, so re-importing a changed edition went on serving the old one until restart. The import now drops the cached archive of a replaced book.
- **Writes that failed without a disk error blocked all later writes.**
  - What happened: a rare IPC failure while saving the reading position (in full suite runs, around the one-file Moby-Dick) stopped the write queue until Retry. Every later save then waited behind it; this is the old intermittent “stored undefined” failure.
  - What changed: such failures are now retried up to three times, with a back-off, before the Retry message.
  - Also: the diagnostic now keeps the error's name and message.
- **The top bar was missing Search.** The Search button had been left out in Phase 4 (⌘F worked); it now shows, with the Notes button, as Screen 03 draws. Contents moved to beside Library, where Screen 03 draws it.
